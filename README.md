# 煎

一个中草药泡茶的交互 demo。

在线体验：<https://guopanqi.github.io/tea-three/>

它只做一件事：**让「等」这段时间变得好看**。

大部分网页交互的本质是把时间压缩到零——点一下，出结果。而泡茶是一种让时间
变得可见的技术。所以这个 demo 里没有进度条、没有倒计时、没有「完成！」，
茶泡好之后不跳转、不结算，就让它停在那儿慢慢凉。允许你什么都不做地待着，
这才是「治愈」真正的意思：它是一种许可，不是一种奖励。

## 跑起来

```bash
npm install
```

```bash
npm run dev
```

## 怎么玩

- **拖**：把桌上的药材拖到杯口，松手，它会掉下去、砸出一圈涟漪、慢慢沉底。
- **按住**：在别处按住不放开始注水。按住的时长决定水量，松手之后还会滴几滴。
- **然后什么都别做**。汤色会自己一点一点出来，大约一分钟到位。水会一直凉下去，
  蒸汽越来越薄，桌上的光非常慢地偏移。
- **底下那条线**是时辰。从月色拖到入夜，七个停靠点：月色、将晓、清晨、正午、
  午后、黄昏、入夜。默认停在午后。平时它几乎看不见，鼠标靠近才浮起来——
  它是一个把手，不是一个仪表盘。

三味药材：洛神花（胭脂红，出色最快）、陈皮（琥珀）、桂圆（暖褐）。
汤色是几味混出来的，也就是说，你放什么、放几样，最后那杯颜色不一样。

## 技术上值得说的几件事

### 汤色不是画出来的，是被吸收剩下的

`src/fluid.js` 是一个 128×128 的 stable-fluids 染料场（平流 → 涡量约束 →
浮力 → 散度 → Jacobi 压力 → 减梯度），它模拟的是杯子内部的一个**竖直切片**。

`src/tea.js` 里的液体是一层**乘性混合**（`blendSrc: ZERO, blendDst: SRC_COLOR`）
的壳。片元着色器做射线-圆锥求交算出在水里的路程，沿视线步进采样染料场，
按 Beer–Lambert 积分出透射率 `T`，直接乘到背景上。

所以杯子里那团红不是一个「颜色」，是光穿过去之后剩下的东西。浓淡随位置变化，
这正是「氤氲」和「均匀染色」的区别。

一开始想用 `MeshPhysicalMaterial` 的 `attenuationColor` / `attenuationDistance`，
放弃了：那条路要 patch three 内部的 `transmission_fragment` chunk（脆），
而且只能给出**均匀**衰减——而不均匀恰恰是全部的重点。

### 玻璃的说服力全部来自逆光

主光在杯子的斜后方。光要穿过它，而不是照在它上面——侧顺光只会得到一只
脏兮兮的塑料杯。

有一个 three 的坑值得记下来：**transmission 只把「不透明队列」渲进折射缓冲**。
桌上那块窗光如果按直觉标成 `transparent: true`，玻璃就完全看不见它，
杯子会变成一根黑管子。所以 `src/stage.js` 里的窗光/焦散/接触阴影全部是
`transparent: false` + `renderOrder` 排序。

杯子背后还必须有一道**横向的亮带**而不是一团均匀的亮：玻璃里需要看到一条
地平线，上下都暗、中间亮。一团均匀的亮只会得到一杯牛奶。

### 一天，和一条不能破的规矩

`src/mood.js` 是七个停靠点，中间连续插值：光的方向和颜色、环境光、色调映射
曝光、雾、背景墙、桌面颜色、桌上窗光的色温，全部一起走。

有一条贯穿始终的约束：**光始终在杯子的斜后方**。太阳可以从很低走到很高、
从偏左走到偏右，但绝不绕到镜头这一侧。一旦变成顺光，玻璃和茶汤立刻就死了。
所以这不是一个天文正确的日照模型，是一间「窗永远在那一边」的屋子。

药材的「透光」也跟着光走（`herbs.applyMood`）。固定一个自发光值的话，
月色下三味药材会像三块烧红的炭——它们不是自己在发光，是光从背后穿过来。

### 光穿过杯子，落在桌上

`src/cuplight.js`。这里原本是两个互不相干的东西：一团椭圆假阴影，和一弯不知道
从哪儿来的焦散。各自都还行，拼在一起读不通——看不出是「同一束光」干的事。

现在全部在同一个坐标系里算：`s` 沿着光在地面上的投射方向，`t` 垂直于它。
影子是杯子这个圆盘从 `s=0` 扫到 `s=run` 的轨迹（`run = 杯高 × 仰角余切`），
焦散是圆柱透镜把光聚到 `s` 某处形成的亮芯，两侧还有两条擦着杯壁过去的亮边。
太阳越低，影子越长、焦散越远——它们一起动，看起来才像一回事。

桌上那块窗光（`stage.js` 的 gobo）也用同一套坐标：**光斑落在哪儿是光线方向
决定的，不能随手摆**。之前它固定在杯子左前方，而影子往右前方倒，两件事对不上，
于是整张桌子看不出光是从哪儿来的。

焦散会被汤色染红，并随浓度变暗——茶越浓，能穿过去的光越少。

### 声音是现场合成的

`src/audio.js` 一个音频文件都不加载。注水声用了一个真实的物理：随着水位上升，
杯里空气柱变短，亥姆霍兹共鸣频率往上爬——所以带通滤波器的中心频率跟着水位走。
人耳对这条上升的线极其敏感，哪怕说不出为什么。

单位体积内，声音提供的情绪密度远高于任何 shader。

### 别的

- 全部程序化生成，零外部资源：木纹、环境贴图、药材几何、蒸汽、浮尘。
- 蒸汽是几片大而软的 billboard 贴滚动噪声，不是粒子喷射（那个太「游戏特效」）。
- 焦散会跟着汤色变红。
- 镜头只有极慢的呼吸和一点指针视差，没有轨道控制——能自由旋转就变成
  「产品展示」了。

## 文件

| | |
|---|---|
| `src/fluid.js` | 染料场求解器 |
| `src/tea.js` | 玻璃杯（车削）、茶汤吸收、水面 |
| `src/stage.js` | 渲染器、光、桌面、窗光、背景墙、浮尘 |
| `src/mood.js` | 一天中的七个时刻 |
| `src/cuplight.js` | 杯影 + 焦散（同一束光的两半） |
| `src/herbs.js` | 三味药材的程序化几何 + 拿起/掉落/沉底/出色 |
| `src/pour.js` | 水柱与余滴 |
| `src/steam.js` | 蒸汽 |
| `src/audio.js` | 全程序化音频 |
| `src/config.js` | 杯子尺寸、光的方向、药材配方 |

调试时 `window.__tea` 挂着所有对象，可以在控制台里直接拧。

## 还没做的

- 这一版是**为一个时刻设计**的：晚上十一点，加班回家，不想说话，想给自己
  弄点热的。为一个时刻设计比为一个人群设计要锋利得多。
- 移动端只做了基本的 pointer 事件，没有认真调过。
- 药材的名字目前跟着指针淡入。更好的做法可能是让它出现在药材旁边的桌面上。
- 「喝」这个动作还没有。
